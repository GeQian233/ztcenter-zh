# 截图说明

本目录所有截图均在 **演示模式**（`--demo`）下生成，不含任何真实节点信息：

| 字段 | 使用的值 | 说明 |
| --- | --- | --- |
| 节点 ID | `a09acf0233` 等 | 虚构地址 |
| 网络 ID | `8767f3abba18a28c` 等 | 虚构地址 |
| 公网路径 | `192.0.2.x` / `198.51.100.x` / `203.0.113.x` | RFC 5737 文档保留段（TEST-NET-1/2/3） |
| IPv6 | `fd00:dead:beef::/64` | ULA 私有段，非真实分配 |
| 世界 ID | `00c0ffee00` | 中性占位值 |
| 网络名称 | `office-lan` / `home-nas` | 虚构 |

如果你要替换为自己的截图，请先脱敏（节点 ID、网络 ID、公网 IP、虚拟 IP、标签里的真实姓名），
可使用仓库内的工具：

```bat
.venv\Scripts\python tools\blur_region.py 原图.png 输出.png 320,180,240,28 --pixel 12
```

区域格式为 `x,y,w,h`，可一次给多个区域；`--blur 12` 可改为高斯模糊。
